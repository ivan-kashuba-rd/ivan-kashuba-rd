# Ivan Kashuba

**Materials Scientist & Process Engineer — Failure Analysis · Process Development · Scientific Computing**

10+ years of hands-on laboratory, R&D and production work in single crystals, polymers, coatings and monomer processes. My core work is root-cause analysis: why a batch went out of specification, why a coating delaminated, why a monomer oligomerized — and which change removes the cause rather than the symptom.

## Focus areas
- **Root-cause and failure analysis** — out-of-spec batches, coating defects and monomer degradation, traced by reading instrument data against process parameters and material condition.
- **Process development** — formulation comparisons, thermal and vacuum processing, filtration, drying, hot extrusion, optical coatings and process documentation.
- **Scientific computing** — engineering calculations rebuilt as reproducible Python with validation checks; daily work with AI coding agents (Claude Code, Codex), verified against tests.

## Selected projects
- [AI Laboratory Document Automation](https://github.com/ivan-kashuba-rd/ai-lab-document-automation)  
  UiPath and FastAPI automation for laboratory document analysis, specification validation and human-review routing. Tested `PASS`, `REVIEW` and `FAIL` workflows with C# Coded Workflows, REST/JSON, SQLite and automated tests.
- [Reactor Dissolution Calculation](https://github.com/ivan-kashuba-rd/reactor-dissolution-calculation)  
  Parameter-driven Python model for evaluating salt dissolution in a stirred reactor using engineering correlations and scenario-based calculations.
- [Pneumatic Dryer Performance Calculator](https://github.com/ivan-kashuba-rd/pneumatic-dryer-performance-calculator)  
  Parameter-driven Python model for evaluating pneumatic tubular drying performance across a gas-velocity range.
- [Stirred-Vessel Heating Comparator](https://github.com/ivan-kashuba-rd/stirred-vessel-heating-comparator)  
  Parameter-driven Python model comparing theoretical heat-transfer performance for paddle, anchor and propeller impellers in a jacketed stirred vessel.
- [Tube-in-Tube Heat Exchanger Scaling Model](https://github.com/ivan-kashuba-rd/tube-in-tube-heat-exchanger-scaling)  
  Python model converting an Excel-based tube-in-tube milk-heating calculation into a reproducible workflow with criteria-based flow screening.
- [PhysChem for Humanity](https://github.com/ivan-kashuba-rd/physchem-for-humanity)  
  Early-stage bilingual (EN/RU) physical chemistry site built with Astro; currently includes an interactive equilibrium calculator.

The calculation projects are educational and theoretical models, not substitutes for validated industrial design calculations.
